# proofpress — 经两种邮件网关的签章校样与装订拼版验收

编辑签发的校样经过两种离线邮件网关送达印厂；印厂用**自持公钥**和**本地装订
设备表**独立解封、核准、拼印，换班制样人再把真实印张折读核对。本实现选择
题目给出的第二种签发办法：

> **编辑签的是部件清单（manifest）**：清单绑定版次、装订方向、实际页序、
> 每一页规范化后的确切内容（解码后 RGB 像素的 SHA-256）、正式批示（全书 /
> 跨页左右页 / 单个折帖三级作用域）以及跨页图的接缝校验值。网关正常展示各
> 页附件；收件端自行解决嵌套替代正文、相同文件名、编码更换的无歧义对应
> （一律按内容哈希的多重集匹配，文件名与部件顺序不携带任何意义）。
>
> 代价与收益都照题面：老式阅读器能看到封面说明与网关送达说明，但**封面说明
> 不自动得到编辑的签章**——演示里改写未签附言，真批示与准印页一个字节也不
> 会变；改动清单或任何一页图则立即拒收。

签名用系统 OpenSSL 3.0 的 Ed25519（`openssl pkeyutl -sign/-verify`），密钥
是本地 PEM 文件；收件席只有编辑**公钥**、自己的店钥、本地工单表与装订合约，
结构上不接触发件席的任何状态（发件日志只存在 `sender/` 下）。

## 目录

```
prooflib/
  compose.py     发送端封装：multipart/mixed → related(alternative 封面+logo)
                 → manifest.json(被签字节) → manifest.sig(Ed25519 分离签名)
                 → 各页图像附件（允许重名）
  gateways.py    网关A：只过7位文本——重写传输编码(QP/base64)、换行宽重折、
                 重折头、重排文本；网关B：8位直通、文本转8bit、
                 顶层加送达说明与追踪头
  manifest.py    清单的规范化 JSON、结构校验、折帖/插页推导出的阅读顺序
  receive.py     印厂收件：遍历嵌套部件(含 message/rfc822)→验签→版次核对→
                 内容哈希多重集匹配→合约可办性→拼版→签发店钥回执；
                 无清单的普通来件照常印（标 UNAPPROVED）
  contract.py    装订合约：纸槽/翻转轴/依次折叠(≥2)/开裁边/插页位置/
                 分帖覆盖；书脊由“折痕闭边−开裁边”推导；可办性校验
  imposition.py  拼版：前向折叠求每帖每面的页位与印刷旋转，输出带定位标
                 （十字规线+裁切角）的正反印张 PNG 与多页 PDF
  foldcheck.py   换班制样人：自己的折法——从印张像素识别页与印刷旋转、
                 折帖、开裁、插页、绕书脊翻叶，导出实际页序与跨缝图；
                 绝不读取邮件中的预期页码充当成品
  geom.py        叶帧(u,v,n)与折叠物理；image.py 无依赖 PNG 编解码与规范化
  keys.py        OpenSSL Ed25519 封装；pdf.py 极简多页 PDF；font.py 3x5 字模
tests/roundtrip.py   几何核心回环自检（4 种合约 × 2 种装订方向，像素级）
demo/run_demo.py     全部验收场景（26 项断言）
```

## 运行

```
./run_all.sh          # 几何回环自检 + 完整演练（26 项检查）
python3 demo/run_demo.py
```

产物在 `demo/out/`：真实 `.eml`（发件箱、两种网关出口、两个印厂信箱）、
各印厂的正反印张 PNG 与 `imposed_book.pdf`、折读报告 `fold_report.json`、
导出的页序 `reading_order.json` 与跨缝图 `spread_p10_p11.png`、店钥签发的
回执 `receipt-*.json(+ .sig)`、普通件 `ordinary_print.pdf`。

## 演练覆盖的验收点

1. 两种网关都正常递信；两印厂纸槽与翻页约定不同 → 拼版不同，折好后读出
   同一份被批准的内容。
2. 合法重投的旧版 + 同名新页同时到信箱：只为与批示相符的版次签收（版次
   不符拒签），另一封普通来件照常印。
3. 改写**未经签署**的附言：原真批示与准印页不变，照样签收；改动清单字节
   或任何一页图：验签失败/页缺失，拒收。
4. 两份同图异批示的折帖：只换第二帖的翻面轴 → 第一帖印张字节不变（原样
   签收），第二帖重新折读、跨页图与批示重新核定；插页位置属于签署内容，
   擅动即不可办。
5. 同一批签件换一份可办的完整装订合约：实际拼版随之改变，装好后仍读出
   相同被批准的内容。
6. 嵌套替代正文、message/rfc822 嵌套转发、附件重名、传输编码更换：
   一律按内容哈希对应，均可验收。
