如何演练

  1. 运行 npm start，打开甲、乙两个终端窗口；选择同一 sid 分支。
  2. 在甲终端发送普通改规格话，在乙终端点“我收到了”；观察消息只被标记为知悉，订单版本不变。
  3. 右侧“立订正”会自动引用旧约定、原文和上下文。选择双边会签时，分别在甲、乙终端点签署；选择具名办法时，甲的署名可在缺席后验真。
  4. 把演练时间设到 21:14 再接受 CR-NAMED-001，仲裁会区分“甲确实出具”与“乙接受迟到、未完成变更”。
  5. 在“证据包”页导出 JSON，交给仲裁席；也可运行 node scripts/verify-evidence.mjs artifacts/xxx-package.json 做独立命令行核验。
