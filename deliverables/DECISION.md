# 交割选择、期限与持有关系

## 结论

对既要求“限期确认”、日后又要“跨馆调阅”的 `QIXIA-KAO v3`，采用：

> **旧见证回条 + 当时核对材料 + 正文精确字节 + 新见证员在旧制度可采信期内出具的移存见证，组成自包含证据包。**

不采用“只凭登记处今日说明”的路线。异馆读者必须能复验历次见证；登记处今天开的“记录有效”新说明，不能替代当年的回条、核对材料和时点凭据。

## 关键期限（本题模拟制度）

| 事项 | 时间 |
|---|---|
| 旧见证员 `old-witness-2023` 有效期间 | 2023-01-01 至 **2026-11-20T23:59:59Z** |
| 替代见证员 `new-witness-2026` 生效 | **2026-09-01T00:00:00Z** 起 |
| 档主材料/移存硬截止 | **不得晚于 2026-11-20T23:59:59Z** |
| 正常示例交割 | 档主 2026-11-18T14:00Z 交件；新见证员 2026-11-19T10:30Z 见证 |
| 晚一天变体 | 2026-11-21T09:15Z 交件；2026-11-21T10:30Z 补见证 |
| “夏季截止前存在”测试截止 | **2026-06-30T23:59:59Z** |

来得及办理的最后边界是旧见证可采信终点 `2026-11-20T23:59:59Z`。实际作业应留出复核时间，因此本方案把正常办理排在 11 月 18–19 日。过了该边界后，新见证员仍可证明“我今天见到了这些材料和旧签名”，但不能把新见证倒签成当年事实，也不能修复已经失去可采信性的旧制度桥梁。

## 谁持有什么

### 跨馆自包含包（所选路线）

- **档主**：可以继续保留原件；在正常路径中于截止前交出与原件逐字节一致的正文/复制本，并签署交割记录。档主不因交件而丧失自己保存原件的权利。
- **档案合作社/承办柜**：保存私钥、密封工作副本和见证日志；私有目录 `cabinet/private` 不交给异馆读者。
- **新见证员**：持有自己的私钥，出具 `migration-attestation`，证明其在旧见证仍可采信时核对了摘要、旧回条签名和当时材料。
- **未来跨馆读者/异馆**：拿到一个 ZIP，其中有正文、旧回条、当年核对记录、交割记录、移存见证、策略、公钥/指纹和独立验证程序。复制到任意临时目录后即可离线复核，不需要读取承办柜，也不需要登记处仍在线。

### 轻量登记续存路线（另一方案，已同时实现）

- **档主/持件人**：保留正文原件，只保存历次轻量回单。
- **受托登记处**：保存连续承诺和续存链；服务期内可供在线核对。
- **陌生读者**：必须拿到持件人带来的原件才能重算摘要；仅凭回单不能把摘要绑定到读者手中的内容。
- **跨馆风险**：若登记处闭馆，规定的在线核对无法再进行。已经签发且完整的签名回单仍可离线验证历史链；但若只有登记处“今天仍有效”的新说明而无历次原始回单，验证必须失败。

## 两个变化的查验结果

1. **登记处后来闭馆**（示例闭馆时间 2026-10-15）：
   - 同一种跨馆书稿的 `qixia-crosslibrary-registry-closed.zip` 仍可离线验证，退出码 `0`，但报告给出 `registry-online-unavailable` 警告；这正是选自包含包的好处。
   - 轻量路线的 `dengying-registry-closed.zip` 也因完整历史回单仍在而离线通过，退出码 `0` 并给出同样警告；但规定的在线登记处核对已不可用。
   - 所选 `qixia-crosslibrary.zip` 本来就不依赖登记处。
   - `registry-statement-only.zip` 只有今日说明，退出码 `2`，断点为 `registry-current-statement` / `history-required`。

2. **档主晚一天交原件**：
   - `qixia-late-delivery.zip` 的签名本身有效，但移存时间为 2026-11-21，晚于旧见证可采信终点。
   - 独立验证器退出码 `2`，断点为 `migration-2026`，首要错误为 `bridge-too-late`（迁移时间晚于旧见证可采信终点）。
   - 系统不会声称已在截止前完成移存，也不会用今日印章倒推当年已见稿。

- 仅把最后一次续存时间改为 `2026-07-02T09:00:00Z`（截止 2026-06-30 之后）并由登记处重新签名后，验证退出码 `2`，断点精确指向 `renewal-4` / `deadline-anchor-late`。
- 恢复及时包后，只把读者带来的原件换成 v2，验证退出码 `2`，断点为 `reader-original`；所有绑定 v1 摘要的旧凭据均报 `digest-mismatch`。旧证明不会给第二版背书。
